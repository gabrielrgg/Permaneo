## 🎯 Sobre o projeto

O **Permaneo** é um projeto desenvolvido para o DemoDay com foco no acompanhamento da frequência dos estudantes. A proposta é reunir informações importantes em uma interface clara, ajudando a equipe escolar a perceber possíveis problemas e planejar ações de acompanhamento.

## ✨ Funcionalidades em destaque

- **Painel geral:** visualização de indicadores, gráficos e alertas relacionados à frequência.
- **Acompanhamento individual:** consulta das informações de cada estudante para identificar quem pode precisar de apoio.
- **Apoio à tomada de decisão:** organização das informações para orientar ações, como conversar com o estudante ou entrar em contato com a família.

> funcionalidades descritas representam a proposta do projeto e podem evoluir durante o desenvolvimento.

## 🛠️ Tecnologias

- **React** — construção da interface e dos componentes.
- **HTML, CSS e JavaScript** — estrutura, estilização e funcionalidades da aplicação.

## 👥 Desenvolvimento em equipe

O projeto é construído de forma colaborativa. Para contribuir:

1. Entre em contato com a equipe responsável pelo repositório e solicite acesso.
2. Atualize sua cópia local antes de começar a trabalhar.
3. Faça suas alterações em uma branch de trabalho.
4. Envie suas alterações e combine com a equipe a revisão antes de integrá-las.
